3. Labeling and the release notes generator: correct sig/* and kind/* labels on issues and PRs drive how the generator (#377) groups changes. [@byrcolin](https://github.com/byrcolin) (SIG-Platform) agreed and will propose AI-assisted issue and PR labeling; SIG-Release supports the proposal. From the 26.10.0 run: 40% of merged PRs had no sig label at merge and 10% had a kind label, so the generator had to place entries by file ownership.
4. Quick Start / Script-only minimum install initiative ([@JT-SCB-GameDesign](https://github.com/JT-SCB-GameDesign)): JT is building a minimal-install onboarding path (Quick Start/Script-only project template with a minimum installer) aimed at engine reviewers, content artists and people who want to play with the demo projects without the full engine environment. Status: the Windows minimum installer has been QA'd (Ninja and CMake configuration changes, simplified build procedure for new QS/So template projects, only Ninja needs installing). Target: fully functional on all supported platforms, documented and ready for promotion with the Spring 2027 release. Per the discussion on the call, JT added code, build and download comments to the docs-side tracking discussion, [o3de/o3de.org#2774](https://github.com/o3de/o3de.org/discussions/2774), which can be followed until a code/build GitHub discussion is started. SIG-Release interest: the minimum installer is a release artifact and a promotion item for 27.05.0.
5. Post-release work: retrospective, 27.05.0 key information issue, README and meetings page fixes, release-day runbook, GitHub Releases cleanup.
